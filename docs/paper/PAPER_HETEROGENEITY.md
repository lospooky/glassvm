# Three publication specimens, one caller contract

Evaluated GlassVM source `ba5637a72d5484ac170069021fbcbc28ee25f61e` and machine source `7cf884861e3cc22d6f15badc7265c969af032e0a`.

CHIP-8 is the baseline/reference implementation. PICO-8 and TIC-80 are external publication-validation specimens, not complete or instruction-exact emulators. Both use bounded Lua 5.4 compatibility runtimes; upstream PICO-8 semantics are not claimed as exact, and upstream TIC-80 targets Lua 5.3. Claims are limited to the documented and tested subsets.

## Shared caller lifecycle

All three use the same caller-owned request and preparation boundary: artifact, typed configuration, input schedule, execution controls, and observation are resolved before execution; PreparedRun remains separate from PreparedObservation. The shared FileRunSession owns sink assembly, execution/evidence accounting, recorder finalization, and atomic publication. Machine-specific schemas, timing, event semantics, and supported subsets remain bundle-owned.
